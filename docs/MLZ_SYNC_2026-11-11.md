## Implementación concreta de este PR: fotografía de Crónica

Se incorporó solamente la experiencia de selección de fotografía, **sin migrar el shell legado**:

1. `MediaControls.tsx` presenta la acción nativa de elegir/cambiar fotografía como tarjeta, con el nombre confirmado por el motor.
2. `controls.css` conserva el tema oscuro de Crónica, estado de foco por teclado y nombre truncado.
3. `media-model.ts` admite `photoName` opcional en el snapshot del bridge; snapshots anteriores siguen siendo válidos.
4. `document-model.ts` guarda `photoName` junto con la foto de cada página. Al crear una página nueva o limpiar una existente, su nombre se reinicia.
5. `engine/legacy-engine.js` publica el nombre tras decodificación exitosa; conserva la identidad estable de página y la política de cancelación de solicitudes anteriores. No actualiza el nombre si una carga falla.
6. El motor no emplea `photoName` para dibujar, reencuadrar ni exportar.

Los nombres se muestran como texto React (sin `innerHTML`) y no se serializan archivos.
